What is a Knowledge Gap?

It is the difference between what you know and what you need to know to solve a problem.

Everyday Example:

You want to cook Thai food but only know how to make sandwiches. The gap is the spices and techniques you haven't learned.

Cybersecurity Example:

Attackers exploit gaps like zero-day vulnerabilities. Defenders must continuously learn to close them.

For Students

  • Build a strong foundation first
  • Practice relentlessly (Hands-on)

For Teachers

  • Use real-world examples
  • Teach "how to learn"

DIKW පිරමීඩය

වටිනාකමේ ධුරාවලිය: දත්තවල සිට ව්‍යවහාරික විනිශ්චය දක්වා.

Wisdom (ප්‍රඥාව)

ව්‍යවහාරික විනිශ්චය. දැනුම භාවිතා කළ යුත්තේ "කවදාද" සහ "ඇයි" දැයි දැන ගැනීම.

Knowledge (දැනුම)

අවබෝධය සහ සන්දර්භය. "එය ක්‍රියා කරන ආකාරය".

Information (තොරතුරු)

අර්ථයක් සහිත දත්ත. "ඉන් අදහස් වන්නේ කුමක්ද යන්න."

Data (දත්ත)

අමු දත්ත සහ සංඛ්‍යා. මූලික ගොඩනැගුම් ඒකක.

Explicit (ලිඛිත/පැහැදිලි)

ලියා ඇති, බෙදා ගැනීමට පහසු. ලේඛන සහ දත්ත සමුදායන්.

  • ආරක්ෂක ප්‍රතිපත්ති
  • Linux Man Pages

Tacit (ව්‍යංග/අත්දැකීම්)

අත්දැකීම් මත පදනම් වූ, විස්තර කිරීමට අපහසු. බුද්ධිය සහ මානසිකත්වය.

  • තර්ජන හඳුනාගැනීමේ ඉව
  • දෝෂ (Bug) සෙවීමේ හැකියාව

Procedural (ක්‍රියා පටිපාටි)

පියවරෙන් පියවර "කළ යුතු ආකාරය". Scripts සහ ක්‍රියාවලීන්.

  • සිද්ධි ප්‍රතිචාර සැලසුම්
  • Bash Scripts

Declarative (ප්‍රකාශිත)

කරුණු සහ නිර්වචන. යමක් සත්‍ය බව "දැන සිටීම".

  • OSI ආකෘතියේ ස්ථර
  • SSH යනු Port 22 වේ

Empirical (ආනුභවික)

නිරීක්ෂණ සහ දත්ත විශ්ලේෂණය තුළින් ලබාගත් දැනුම.

  • සේවාදායක ලොග් විශ්ලේෂණය
  • Pen-testing සොයාගැනීම්

Theoretical (න්‍යායික)

වියුක්ත මූලධර්ම සහ ආකෘති. තාක්ෂණය පිටුපස ඇති "ඇයි" යන්න.

  • ගුප්තකේතන ගණිතය (Encryption)
  • Big O සංකීර්ණත්වය

Practical (ප්‍රායෝගික)

අත්දැකීම් සහිත කුසලතා. භෞතිකව හෝ සෘජුවම භාවිතා කිරීම.

  • Ethernet කේබල් සකස් කිරීම
  • සර්වර් (Servers) සවිකිරීම

A Priori (පූර්ව නිගමන)

අත්දැකීම් වලින් ස්වායක්තව ලබාගත් දැනුම. තර්කානුකූල නිගමන.

  • Boolean තර්කනය
  • Subnetting තර්කනය

A Posteriori (පශ්චාත් නිගමන)

අත්දැකීම් හෝ සාක්ෂි මත පදනම් වූ දැනුම.

  • "මේ සර්වර් එක වැඩ නැහැ"
  • Forensic සාක්ෂි

Linguistic (භාෂාමය)

වාක්‍ය ඛණ්ඩ, සංකේත සහ භාෂා ව්‍යුහයන් අවබෝධ කර ගැනීම.

  • Code Syntax
  • Regex රටා

එය ගැටලුවක් විසඳීමට ඔබ දන්නා දේ සහ ඔබ දැනගත යුතු දේ අතර වෙනසයි.

එදිනෙදා උදාහරණයක්:

ඔබට තායි ආහාර පිසීමට අවශ්‍ය නමුත් ඔබ දන්නේ සැන්ඩ්විච් සාදා ගන්නේ කෙසේද යන්න පමණි. පරතරය යනු ඔබ තවමත් ඉගෙන ගෙන නැති කුළුබඩු, ක්‍රම සහ වට්ටෝරු වේ.
