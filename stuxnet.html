Design System

CRISIS UX

Design principles for Flood Response & High-Stress Environments.

01. Combat Cognitive Tunneling

Under stress, user attention narrows. Remove choices.

Standard UI (Too Complex)
Crisis UI (Focused)

02. Universal Color

Critical / SOS
Life threatening. Immediate action.
Supplies Need
Food, Water, Shelter.
Safe / Done
Rescue complete. Area clear.
Contrast Ratio
AAA Use Pure Black (#000000)
for OLED power saving

03. The Thumb Zone

Users hold wet phones with one hand. Key actions must be at the bottom.

Hard to Reach
Natural Thumb Zone
PRIMARY ACTION

04. Offline-First Architecture

User Taps

Instant feedback. UI turns Green immediately.

Local Queue

Data stored on device. App retries in background.

Auto-Sync

Data uploads only when signal is found.

05. Input Optimization

Typing is impossible in rain. Use Chips, GPS, and Voice.

No Typing
Voice Input
Auto-GPS
